Good to know

A few quick answers.

Does OCRBook change my original PDF?

No. Your original file stays untouched. OCR text is stored separately, so you can switch between the scan and TXT view anytime.

Can I use OCRBook offline?

Yes. OCR and reading work offline. Ollama features need a network connection only when your configured server is on another device.

What happens with a very long document?

OCRBook plans around the context length you choose. It can split the document, summarize each part, and merge the results without silently dropping the end.

Can I stop a summary after it starts?

Yes. The workflow shows visible progress and can be cancelled at any time, which stops OCRBook from sending further requests.
